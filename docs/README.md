# Project-Helix Documentation

This directory contains the documentation files for the viva, project presentation, and defense:

1. `ER_Diagram.md` & `ER_Diagram.pdf` — Entity-Relationship Diagram covering the 9 3NF normalized tables (7 Strong, 2 Associative Entities, 52 attributes).
2. `SRS.md` & `SRS.pdf` — Software Requirements Specification outlining system constraints, user roles, and functional requirements.
3. `User_Manual.md` & `User_Manual.pdf` — Complete user guide for founders, team members, and investors using Project-Helix.
4. `ARCHITECTURE_FLOWCHART.md` & `request_flow_diagram.jpg` — Detailed request-response lifecycle flowchart and infographic diagram.
5. `VIVA_EXPLANATION_GUIDE.md` — Comprehensive viva defense guide with top 15 questions and answers.
6. `VIDEO_PRESENTATION_SCRIPT.md` — Timed 2-minute video presentation script.
