# Project-Helix Documentation

This directory contains the documentation files for the viva and project presentation:

1. `ER_Diagram.pdf` - Entity-Relationship Diagram covering 18 3NF normalized tables.
2. `SRS.pdf` - Software Requirements Specification outlining system constraints, user roles, and functional requirements.
3. `User_Manual.pdf` - Complete user guide for founders, investors, and administrators using Project-Helix.
